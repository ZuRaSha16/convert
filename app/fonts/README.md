# Georgian fonts

- `alk-sanet.ttf`: supplied ALK Sanet font, used for general Georgian text.
- `geo-dedaena.ttf`: supplied Geo Dedaena Regular from `Geo Dedaena [typeface.ge].zip`, used only for the four heading phrases and the final obligations-strip label marked `georgian-accent` in Georgian mode.

Geo Dedaena's original character map uses Latin keyboard positions for Georgian glyphs. Its web copy maps U+10D0–U+10F0, in alphabetic order, to the original glyphs at `abgdevzTiklmnopJrstufqRySCcZwWxjh`. Space and period are retained. Glyph outlines, metrics, names, and other font tables are unchanged; font checksums are recalculated. This lets the page retain actual Unicode Georgian text for selection, search, and accessibility.
